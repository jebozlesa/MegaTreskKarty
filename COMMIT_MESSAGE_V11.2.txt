V11.2: Bleed effect system - Unity client changes

Individual Bleed animations and death check support.

Changes:
- BattleResultProcessor.cs
  * Parse bleedDamages array from server response
  * Loop through individual Bleed damages with 0.3s delays
  * Renamed PlayBleedDamageAnimation → PlaySingleBleedAnimation
  * Added animation loops in all 4 battle flow branches:
    - I attack first → My Bleed → Enemy Bleed
    - Enemy attacks first → Enemy Bleed → My Bleed
  * Updated function signatures to accept List<int> bleedDamages

- Kard.cs
  * Made RepositionEffectIcons() public
  * Allows BattleResultProcessor to reposition icons after adding

Visual Changes:
- Multiple Bleed effects now show as separate animations
- 0.3s delay between each Bleed animation
- HP bar updates after each individual Bleed
- Dialog shows for each Bleed ("X is bleeding! -Y HP")

Example:
Card has 3 Bleed effects (2, 3, 4 damage):
1. Animation 1: -2 HP → HP bar updates → Dialog
2. Wait 0.3s
3. Animation 2: -3 HP → HP bar updates → Dialog
4. Wait 0.3s
5. Animation 3: -4 HP → HP bar updates → Dialog

Files Modified:
- Assets/Scripts/Multiplayer/BattleResultProcessor.cs (4 locations)
- Assets/Scripts/Kard.cs (1 line)

Testing:
✓ Individual Bleed animations play correctly
✓ HP bar updates after each Bleed
✓ Effect icons reposition without overlap
✓ Works in both attack order scenarios

Dependencies:
- Requires server V11.2 with bleedDamages array support
- Compatible with existing animation system
- No new assets required
